# Prompts utilizados

## Prompt para criação do conceito

Crie o conceito de uma campanha de e-commerce para uma garrafa térmica fictícia de 750ml. O público deve incluir pessoas que trabalham, estudam, praticam esportes e fazem atividades ao ar livre. Desenvolva uma proposta de valor clara, benefícios e uma chamada para ação.

## Prompt para texto publicitário

Crie um texto publicitário profissional para uma garrafa térmica fictícia chamada Nexa Outdoor 750ml. O texto deve destacar praticidade, transporte, uso cotidiano e atividades ao ar livre. Evite exageros e mantenha linguagem comercial.

## Prompt para imagem

Crie uma peça publicitária profissional para uma garrafa térmica fictícia de 750ml chamada Nexa Outdoor. Mostrar o produto em destaque em um ambiente externo com montanhas ao fundo. Utilizar composição de anúncio de e-commerce, iluminação natural, aparência premium e informações visuais organizadas. Incluir benefícios, situações de uso e chamada para ação.
